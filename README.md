## 🧠 What I do

I design the system, train and serve the model, build the backend it talks to, and run the infra underneath it.

- 🤖 **AI in production**: LLM apps, RAG, embeddings, real-time inference, voice pipelines. Agricultural AI for Gujarati dairy farmers, B2B intent monitoring engines, medical imaging (diabetic retinopathy) screening.
- 🏗️ **Architecture**: config-driven pipelines, event-driven services, clean API contracts. Build once, point it at the next problem.
- ☁️ **Infra**: AWS, GCP, Docker, CI/CD, Nginx, monitoring. Boring on purpose.
- ⚙️ **Backend and DB**: FastAPI, Node, Python services; Postgres, Redis, Mongo, Kafka, ClickHouse. Indexing and query plans before scaling hardware.
- 📊 **Research**: econometrics replication for an NBER-linked team, biomedical papers headed to Scopus.
- 🌐 **Web and mobile**: React, Next.js, Vite, React Native, Flutter. Animated, performance-tuned frontends when the product needs a face.
